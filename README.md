# 🚇 Tunnel Panel — پنل مدیریت تونل بین سرورها

پنل وب فارسی برای ساخت و مدیریت تونل بین چند سرور، با نصب تک‌لینکی ایجنت روی هر سرور.

| قابلیت | توضیح |
|---|---|
| **Forward Tunnel** | گوش دادن روی یک پورت از سرور و فوروارد مستقیم به `IP:Port` مقصد — TCP و UDP |
| **Reverse Tunnel** | سرور مقصد بدون IP عمومی / پشت NAT هم قابل دسترس می‌شود (مشابه FRP/Rathole) — TCP |
| **نصب ایجنت با یک لینک** | از داخل پنل برای هر سرور یک دستور تک‌خطی می‌گیرید؛ ایجنت فقط با Python 3 استاندارد کار می‌کند (بدون pip) |
| **مانیتورینگ** | وضعیت آنلاین سرورها، ترافیک ورودی/خروجی هر تونل، تعداد کانکشن، نمودار ۲۴ ساعته |
| **مدیریت کامل** | چندکاربره (ادمین/کاربر)، محدودیت حجم ترافیک، تاریخ انقضا، فعال/غیرفعال کردن تونل |
| **نصب پنل** | با اسکریپت bash (systemd) یا Docker |

---

## 🚀 نصب پنل

### نصب تک‌لینکی روی سرور (سریع‌ترین راه)
```bash
bash <(curl -Ls https://raw.githubusercontent.com/Hosein21378/tunnel-panel/main/install.sh)
```


### روش ۱ — Docker (سریع‌ترین)
```bash
git clone https://github.com/Hosein21378/tunnel-panel.git && cd tunnel-panel
SECRET_KEY=$(openssl rand -hex 32) ADMIN_PASSWORD=[SECURITY_DATA] docker compose up -d --build
```
پنل: `http://SERVER_IP:8080` — ورود با `admin` و رمزی که ست کردید.

### روش ۲ — اسکریپت نصب (systemd)
```bash
git clone https://github.com/Hosein21378/tunnel-panel.git && cd tunnel-panel
sudo bash install.sh --mode panel
```
رمز ادمین تصادفی ساخته و نمایش داده می‌شود (در `/opt/tunnel-panel/.env` هم ذخیره می‌شود).
```bash
journalctl -u tunnel-panel -f   # لاگ پنل
```

> ⚠️ قبل از استفاده واقعی: رمز ادمین را عوض کنید، `SECRET_KEY` را تصادفی بگذارید و روی پنل HTTPS بگذارید (مثلاً با Nginx/Caddy ریورس‌پروکسی).

## 🖥️ افزودن سرور (نصب ایجنت با یک لینک)

1. در پنل وارد تب **«سرورها»** شوید و «افزودن سرور» را بزنید.
   - برای سرورهایی که IP عمومی دارند، **آدرس عمومی** (IP یا دامین) را حتماً وارد کنید.
2. پنل یک دستور تک‌خطی می‌دهد؛ همان را روی سرور مقصد اجرا کنید:
```bash
bash <(curl -Ls http://PANEL:8080/install-agent.sh) --panel http://PANEL:8080 --token XXXXX
```
3. ایجنت دانلود، نصب و به‌صورت سرویس `tunnel-agent` اجرا می‌شود و سرور در پنل **آنلاین** می‌شود:
```bash
systemctl status tunnel-agent
journalctl -u tunnel-agent -f
```

نیازمندی ایجنت: فقط `python3` (۳٫۸+) — هیچ پکیجی نصب نمی‌شود.

## 🔀 ساخت تونل

### Forward — فوروارد مستقیم
ترافیک پورت ورودی **سرور مبدا** مستقیم به `Target Host:Target Port` فرستاده می‌شود. (TCP / UDP / هر دو)

**مثال:** دیتابیس روی سرور B فقط از طریق سرور A در دسترس باشد:
نوع=Forward، سرور مبدا=A، پورت ورودی=5432، مقصد=`IP_B:5432`

### Reverse — سرور پشت NAT
**سرور مبدا** = سرور عمومی (ورودی اینترنت) | **سرور مقصد** = سروری که پشت NAT است و خودش به سرور عمومی وصل می‌شود | مقصد = سرویس لوکال روی سرور مقصد (معمولاً `127.0.0.1`).

**مثال:** دسترسی SSH به سرور خانگی بدون IP عمومی:
نوع=Reverse، سرور مبدا=سرور عمومی، پورت ورودی=2222، سرور مقصد=سرور خانگی، مقصد=`127.0.0.1:22`
```bash
ssh -p 2222 user@PUBLIC_SERVER_IP
```

### نکات شبکه
- پورت ورودی هر تونل روی سرور مبدا باید در فایروال باز باشد: `ufw allow 2222/tcp`
- پورت **Relay** (پیش‌فرض `10000`) روی سرور عمومی باید باز باشد تا ایجنت‌های مقصد وصل شوند:
  `ufw allow 10000/tcp` — قابل تغییر با `--relay-port` هنگام نصب ایجنت.
- روی یک سرور، هر پورت ورودی فقط برای یک تونل فعال قابل استفاده است (پنل جلوی تداخل را می‌گیرد).

## 👥 کاربران و امنیت
- **ادمین:** همه سرورها، تونل‌ها و کاربران را می‌بیند و مدیریت می‌کند.
- **کاربر عادی:** فقط تونل‌های خودش را می‌بیند؛ برای هر تونل می‌توان سقف ترافیک (GB) و تاریخ انقضا گذاشت.
- ارتباط ایجنت و پنل با توکن اختصاصی هر سرور انجام می‌شود — دستور نصب هر سرور را مثل رمز نگه دارید.
- در صورت لو رفتن توکن یک سرور: آن را در پنل حذف و دوباره بسازید.

## 🧩 ساختار پروژه
```
tunnel-panel/
├── install.sh               # نصب پنل (systemd) یا ایجنت
├── docker-compose.yml       # اجرای پنل با داکر
├── Dockerfile
├── panel/app/
│   ├── main.py              # API پنل + API ایجنت + سرو فایل نصب
│   ├── models.py            # دیتابیس: کاربر، سرور، تونل، آمار
│   ├── security.py          # JWT + هش رمز
│   └── static/              # رابط وب فارسی (HTML/CSS/JS)
├── agent/agent.py           # ایجنت سبک (فقط stdlib پایتون)
└── scripts/agent-install.sh # اسکریپت نصب ایجنت (از خود پنل سرو می‌شود)
```

## ⚙️ اجرای دستی برای توسعه
```bash
pip install -r requirements.txt
SECRET_KEY=dev ADMIN_PASSWORD=admin123 uvicorn app.main:app --app-dir panel --host 0.0.0.0 --port 8080
# ایجنت:
python3 agent/agent.py --panel http://127.0.0.1:8080 --token TOKEN --relay-port 10000
```

## ❓ عیب‌یابی
| مشکل | راه‌حل |
|---|---|
| سرور آفلاین می‌ماند | `journalctl -u tunnel-agent -f` — دسترسی سرور به آدرس پنل و درستی توکن را چک کنید |
| تونل ریورس وصل نمی‌شود | پورت Relay (10000) روی سرور عمومی باز است؟ «آدرس عمومی» سرور مبدا در پنل وارد شده؟ ایجنت مقصد آنلاین است؟ |
| پورت اشغال است | تونل دیگری روی همان سرور و پورت فعال است یا سرویس دیگری آن پورت را گرفته (`ss -tlnp`) |
| ترافیک ثبت نمی‌شود | چند ثانیه صبر کنید؛ ایجنت هر ۱۰ ثانیه آمار را گزارش می‌کند |
